## Código adicional extraído do projeto autenticado

O FlutterFlow não liberou `Download Code` no plano atual. Os arquivos abaixo foram copiados integralmente pela área `View Code` do projeto autenticado.

- `components/`: 70 componentes, cada um com seu Widget e Model em arquivos separados.
- `custom_functions/`: 22 funções customizadas em Dart.
- `project_config/pubspec.yaml`: dependências e configuração do projeto.
- `project_config/firestore_indexes.json`: índices do Firestore disponíveis no projeto.

Os arquivos de página e os documentos Word extraídos anteriormente permanecem na pasta raiz de `extracted_code`.
